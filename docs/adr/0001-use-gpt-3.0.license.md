# 1. Use of the GPL-3.0 license

Date: 2026-07-14

## Status

Accepted

## Context

We need to choose the main license for Wasteland. We considering various options, such as MIT and Apache-2.0.
Our goal was to ensure that derivative works remained open (copyleft) rather than
being used in closed commercial projects without contributing back to the community.

## Decision

We use GPL-3.0 as the main license of the project.
